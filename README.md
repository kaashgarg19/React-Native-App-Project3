# Eventrum — Event Finder Mobile App

Eventrum was one of my larger early React Native projects. The idea was to let a user search for events and view event details and locations from a mobile interface.

## What I built

- multi-screen navigation
- event search
- event details
- external event links
- location/geocoding support
- Firebase authentication
- Redux-based state handling

## Data and services

The original project used event data from Eventbrite and geocoding services for location information. Firebase was used for authentication and user data.

## Technologies

React Native · JavaScript · Firebase · Redux · Eventbrite API · Geocoding

## What I learned

The project gave me practical experience with navigation, API calls, JSON responses, authentication and handling data across several screens.

## Project status

This is an older coursework/prototype project. Some planned features were not completed, including the Facebook sign-in experiment and a favourites feature.

The config files are part of the original coursework. They should not be reused as credentials for a new application, and the old Facebook login code should be treated as unfinished prototype code rather than production authentication.
